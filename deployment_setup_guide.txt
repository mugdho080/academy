# Complete Setup Guide: GitHub + Local AI + GoDaddy Deployment

This guide explains how to push your code to GitHub, continue using Antigravity/Codex locally with your GitHub repository, and deploy to GoDaddy into the `public_html/academy` folder with phpMyAdmin.

---

## Part 1: GitHub & Local AI Setup

The best workflow is to keep your code on your local computer, sync it to GitHub for backup and version control, and use your AI tools locally (like VS Code + Antigravity/Cursor/Codex).

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com/) and create a new repository (e.g., `goodwill-care-academy`). Don't initialize it with a README.

2. **Initialize Git Locally**:
   - Open simply terminal/command prompt in your local project folder (`C:\Users\user\Downloads\academy`).
   - Run the following commands:
     ```bash
     git init
     git add .
     git commit -m "Initial commit for Goodwill Care Academy"
     git branch -M main
     git remote add origin https://github.com/YOUR_USERNAME/goodwill-care-academy.git
     git push -u origin main
     ```

3. **Continue Using Local AI (Codex/Antigravity)**:
   - Your local AI tools can now see the "Git" history. As you use Antigravity, changes will be tracked.
   - You can push changes generated by the AI to GitHub anytime by running:
     ```bash
     git add .
     git commit -m "AI updates"
     git push
     ```

## Part 2: Preparing the App for GoDaddy (Subdirectory)

Since you are hosting the app inside the folder `academy` (`public_html/academy`), your URL will be something like `https://yourdomain.com/academy/`. 

Before deploying, we need to make 3 small code changes so the app knows it's living in a subfolder:

1. **Update `vite.config.js` Base URL**:
   Open `vite.config.js` and add `base: '/academy/',` right above the server settings:
   ```javascript
   export default defineConfig({
     base: '/academy/',   // <--- ADD THIS LINE FOR GODADDY SUBDIRECTORY
     plugins: [react()],
     // ... rest of config
   })
   ```

2. **Fix API Requests for Production**:
   Currently, the React app makes requests to `/api/...` (e.g., `/api/auth/login`). On GoDaddy, this has to go to `/academy/api/...`.
   Open `src/main.jsx` (or `src/App.jsx`) and inject a global base URL for Axios at the very top:
   ```javascript
   import axios from 'axios';
   // If the app is in production (GoDaddy), prepend /academy to all API calls.
   if (import.meta.env.PROD) {
       axios.defaults.baseURL = '/academy'; 
   }
   ```

3. **Database Connection Configuration**:
   Open your database config file (usually `api/db_connect.php`). 
   You will need to change the credentials to match your GoDaddy database (which we will create below), but keep local ones as a fallback or simply change them right before uploading.

---

## Part 3: GoDaddy & phpMyAdmin Setup

### Step A: Database Setup
1. Log into your GoDaddy cPanel.
2. Go to **MySQL® Databases**.
3. Create a new database (e.g., `yourdomain_academy`).
4. Create a new User (e.g., `yourdomain_dbuser`) with a strong password. Save this password!
5. Add the User to the Database and assign **ALL PRIVILEGES**.
6. Export your local database: Open your local phpMyAdmin (`http://localhost/phpmyadmin`), select your `academy` database, go to the Export tab, and save the `.sql` file.
7. Go back to GoDaddy cPanel, open **phpMyAdmin**, select your new database (`yourdomain_academy`), go to the Import tab, and upload your `.sql` file.
8. Edit `api/db_connect.php` with this new database name, user, and password.

### Step B: Build and Upload
1. Build the frontend locally. In your terminal (`C:\Users\user\Downloads\academy`), run:
   ```bash
   npm run build
   ```
   *This creates a `dist` folder with your compressed, production-ready frontend.*

2. Go to your GoDaddy cPanel -> **File Manager** -> open `public_html` -> create a folder named `academy` -> open it.

3. Upload the contents:
   - **Upload Frontend**: Open your local `dist` folder. Zip everything inside `dist` (index.html, assets folder, etc.), upload the zip to `public_html/academy`, and extract it. 
   - **Upload Backend**: Zip your local `api` folder, upload it to `public_html/academy`, and extract it.
   - **Upload Assets**: Zip your local `uploads` folder (if it contains user avatars/signatures) and extract it to `public_html/academy` as well.

### Folder Structure Verification
Your `public_html/academy` folder in GoDaddy should look exactly like this:
```text
public_html/
└── academy/
    ├── index.html        (from your dist folder)
    ├── assets/           (from your dist folder)
    ├── api/              (your PHP scripts directory)
    └── uploads/          (your uploads directory)
```

## Done!
You can now visit your app at `https://yourdomain.com/academy/`. Whenever you use Antigravity locally to add new features, just run `npm run build` and re-upload the `dist` files and any updated `api` files!
